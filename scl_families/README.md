Driving families (`fail2drive`): `routes/` holds one leaderboard-format route XML per accepted variant, byte-identical to the file the measurement campaigns ran; `variants.csv` is the catalog (target factor value and the measured, in-simulator verified geometry; a `refused` row has no route). Run a route with the vendored harness (`docs/RUNNING.md`).

Warehouse families (`isaac`): a variant is a stage the SCL runner compiles from `family_manifest.json` at run time, so there is no route file; `variants.csv` lists the manifest's variants (stem, target gap, measured gap, passable or blocked, certified). Running them needs Isaac Sim 5.1 and the SCL runner, which is not released; the scoring chain under `scl/` re-scores the published bundles.
